# Nothing monochrome / Serpentinum

Пресет и адаптация панели для присланной версии Serpentinum вместо замены
его функций отдельными Waybar и Mako. Не входит в `scripts/install.sh`
и пока не проверен в запущенной Linux-сессии.

Инструкция применения панели: [INSTALL.md](INSTALL.md).
Не копировать поверх settings.json целиком: это частичный набор переопределений,
который нужно объединить с настройками установленной версии.

## Визуальное направление

- Верхний бар: рабочие столы и музыка слева, часы по центру, статусы справа.
- Чёрный, белый и нейтральные серые; роль `red` тоже белая.
- Автоокрашивание от обоев выключено. Пользовательские цвета групп и
  индивидуальных виджетов нужно проверить отдельно по текущим настройкам.
- Сохранить панель календаря и погоды Serpentinum: календарь слева,
  крупные часы и почасовой прогноз в центре, текущая погода справа.
- Виджеты рабочего стола: крупные точечные часы, погодная карточка,
  музыкальная карточка и круглый индикатор батареи в эстетике Nothing.
- Ndot для крупных чисел и заголовков; читаемый шрифт для длинного текста.
  Глобальный `fontFamily` в JSON — предварительный вариант: раздельные
  шрифты и собственная геометрия карточек могут потребовать изменений QML.

## Что нужно перед интеграцией

1. settings.json с ноутбука и версия установленного Serpentinum.
2. Подобрать точечное начертание для крупных часов: пользователю не нравится
   имеющийся Ndot 55. Не заменять его другим шрифтом под именем Ndot.
3. Проверка схемы виджетов и панели установленной версии.
4. Резервная копия, объединение настроек без потери города, устройств,
   расположения виджетов и остальных пользовательских параметров.
5. Возврат `serpantinumd start` в Niri одновременно с отключением Waybar
   и Mako, проверка блокировки и уведомлений.

Сам шрифт в репозиторий не включён. Один fontFamily не устанавливает Ndot.
Пока не подготовлена интеграция, старый установщик использовать для этого
пресета нельзя: он устанавливает предыдущий вариант с Waybar.

## Подготовка без установки

Полученные настройки уже используют монохромную палитру Obsidian и Ndot 55
глобально. Пресет переключает основной текст на JetBrains Mono; раздельный
точечный шрифт часов требует отдельной реализации в QML.

```sh
python3 scripts/prepare-serpantinum.py \
  ~/.config/serpantinum/settings.json \
  --output /tmp/nothing-settings-candidate.json
```

Команда только создаёт новый JSON; не перезапускает оболочку, не меняет Niri
и не устанавливает тему. Исходный файл, город и прочие настройки сохраняются.
Существующий выходной файл не перезаписывается. Личные настройки и координаты
не добавлять в репозиторий. Схему и визуальный результат нужно проверить на
установленной версии Serpentinum перед применением.
