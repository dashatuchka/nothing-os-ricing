# Панель Nothing / Serpentinum

Это обновление панели календаря и погоды, темы и верхнего бара.
Новые отдельные виджеты рабочего стола сюда пока не входят.
Настоящий Ndot 55 используется только для крупных цифр панели; подписи —
JetBrains Mono, погодные иконки — встроенный шрифт иконок Serpentinum.
Другой шрифт не скачивается и не выдаётся за Ndot.

## Подготовка на Arch

Распакуй новый архив в отдельную папку и открой её в терминале.
Уже работающий Serpentinum и его зависимости должны оставаться установленными.

```sh
python3 scripts/style-serpantinum.py --output /tmp/nothing-panel-preview
```

Это только подготовка четырёх файлов без изменения системы. Папка результата
должна быть новой. Скрипт сверяет SHA-256 обоих QML с присланной версией и
отказывается менять неизвестную версию. Не обновляй Serpentinum перед применением.

Если предварительная подготовка успешна, выйди из Niri через Super+Shift+E,
подтверди выход, затем перейди в Ctrl+Alt+F3 и войди под своим пользователем.
Перейди в каталог распакованного проекта.

```sh
python3 scripts/style-serpantinum.py --apply
niri validate
```

Запускай без sudo. Скрипт:

- создаёт копии обоих QML, settings.json и конфига Niri;
- меняет оформление панели, сохраняя её данные, календарь и орбитальный прогноз;
- объединяет тему с настройками, сохраняя город и прочие пользовательские поля;
- убирает прямой запуск Waybar и Mako из Niri, возвращает `serpantinumd start`;
- не меняет гритер, пакеты, службы и расположение виджетов рабочего стола.

Путь бэкапа и готовая команда отката появятся в выводе. Сохрани их.
При ошибке `niri validate` выполни откат до входа в графическую сессию.
После успешной проверки перезагрузи ноутбук и войди в прежнюю сессию Niri.
Панель открывается штатным нажатием на часы Serpentinum.

Если Waybar или Mako запускаются отдельной службой или через XDG autostart,
этот скрипт их не отключает. Не запускай две оболочки одновременно.

## Откат

Выйди из графической сессии и выполняй из TTY:

```sh
python3 scripts/style-serpantinum.py --restore ПУТЬ_БЭКАПА
niri validate
```

`ПУТЬ_БЭКАПА` замени точным путём из вывода установщика.
Откат возвращает все четыре файла; текущие файлы также сохраняются рядом
с резервной копией. После успешной проверки перезагрузи ноутбук.

## Если файл не найден

Если Python пишет `can't open file ... scripts/style-serpantinum.py`,
терминал открыт не в папке новой версии проекта. В каталоге проекта команда
`ls scripts/style-serpantinum.py` должна показать файл. Старый архив с Waybar
не содержит этого скрипта.

Если ошибка начинается с `Missing file:`, скопируй полный путь из сообщения.
Путь к установленной оболочке можно задать явно:

```sh
python3 scripts/style-serpantinum.py \
  --source ~/.local/share/serpantinum/src/quickshell \
  --output /tmp/nothing-panel-preview
```

## Проверки и ограничения

На копиях присланных файлов проверены отсутствие изменений при preview,
применение, точный откат, сохранение general и отказ для другой версии QML.
На macOS нет Quickshell/QML-инструментов: загрузка QML и визуальный результат
требуют проверки на Arch. Это адаптация панели, а не завершённый набор новых
Nothing-виджетов.

Модификации QML основаны на Serpentinum (Illia Miroshnichenko, AGPL-3.0-or-later):
https://github.com/ilyamiro/serpantinum. Исходные файлы не включены в архив;
преобразования находятся в scripts/style-serpantinum.py. Применённые изменения
QML распространяются на условиях лицензии исходного проекта.
