# Nothing для Niri — оболочка по референсу Glyph

Эта версия заменяет оболочку целиком: фон с сеткой и полутоновым шаром,
крупные часы, бенто-виджеты, верхний бар, лаунчер, уведомления и центр управления.
Весь интерфейс чёрно-белый. Панель по нажатию на часы сочетает календарь,
орбитальный почасовой прогноз и текущую погоду, как в присланном Serpentinum.
Гритер и установленный Serpentinum сохраняются для отката.

**Не запускай старые `install.sh` и `style-serpantinum.py` для этой версии.**
Они устанавливают предыдущие варианты.

## Зависимости на Arch

```bash
sudo pacman -Syu --needed quickshell python fontconfig \
  ttf-jetbrains-mono-nerd curl cava brightnessctl \
  swaylock pavucontrol network-manager-applet blueman
```

Предполагаются уже работающие Niri, PipeWire, NetworkManager и Bluetooth.
CPU-профили доступны только при установленном и работающем power-profiles-daemon.
Встроенные Space Grotesk, Space Mono и Doto загружаются самой оболочкой.

## Подготовка без изменения сеанса

Из папки новой версии проекта:

```bash
python3 scripts/install-nothing.py \
  --download-ndot --output /tmp/nothing-full-preview
```

Скрипт скачивает проверенный Ndot 57 отдельно от репозитория, проверяет SHA-256
и семейство через fontconfig, подготавливает файлы и запускает `niri validate`.
Текущие настройки не заменяются. Выходная папка должна быть новой.

Если шрифт уже скачан:

```bash
python3 scripts/install-nothing.py \
  --dot-font ~/Downloads/Ndot57-Regular.otf --output /tmp/nothing-full-preview
```

Без обоих параметров используется явно названный Doto, как у автора референса.
Ndot 55 не назначается мелким подписям. Файл Ndot в Git не включён.

## Установка

Выйди из Niri, перейди в TTY через Ctrl+Alt+F3, войди и перейди в папку проекта.

```bash
python3 scripts/install-nothing.py --apply --download-ndot
niri validate
```

Либо укажи `--dot-font` вместо `--download-ndot`, если переносишь шрифт файлом.
Запускай без sudo. Сохрани напечатанную команду отката.
После успешной проверки перезагрузи ноутбук и войди в обычную сессию Niri.

Установщик сохраняет предыдущие файлы, затем:

- устанавливает отдельную оболочку в `~/.config/quickshell/nothing`;
- создаёт её собственные настройки в `~/.config/nothing-niri` и состояние в
  `${XDG_STATE_HOME:-~/.local/state}/nothing-niri`;
- переносит только город, координаты и часовой пояс из настроек Serpentinum;
- убирает прямой запуск Serpentinum, Waybar, Mako, swaybg и старых qs из Niri;
- запускает новую оболочку, которая сама рисует фон;
- сохраняет монитор, раскладки, терминал, полкит, буфер обмена и остальные бинды.

Программы, старые обои и их исходные настройки не удаляются.
Файлы внутри установленного Serpentinum больше не патчатся.
Службы systemd user и XDG autostart установщик не меняет: если старый бар
запускается оттуда, такой автозапуск нужно отключить отдельно.

## Управление

| Действие | Клавиши |
| --- | --- |
| Приложения | Super+D или знак в баре |
| Центр управления, звук, виджеты, уведомления | Super+A или статусы в баре |
| Календарь и орбитальный прогноз | Super+N, часы в баре, виджет погоды/календаря |
| Нижний дашборд | Super+Shift+D |
| Терминал | прежний Super+T |
| Обзор Niri | прежний Super+Space |
| Блокировка | прежний Super+Alt+L |

В центре управления можно менять состав виджетов, светлую/тёмную тему,
включать DND и сравнивать Ndot с Doto. Город берётся из старых настроек.
Погода и показатели системы настоящие; если данных нет, показывается ожидание.

## Откат

Из TTY, после выхода из Niri:

```bash
python3 scripts/install-nothing.py --restore ПУТЬ_ИЗ_ВЫВОДА_УСТАНОВЩИКА
niri validate
```

Вернутся предыдущий конфиг Niri и состояние заменённых файлов. Перед откатом
текущая версия тоже сохраняется. После успешной проверки перезагрузи ноутбук.

## Что проверено

В тестовом Arch-контейнере оболочка запущена в настоящем вложенном Niri 26.04
с Quickshell 0.3.2 и Qt 6.12. Проверены домашний экран, календарь с реальными
данными Open-Meteo, центр управления и лаунчер через IPC. Ошибок загрузки QML
и JS-привязок после открытия панелей не обнаружено. Предупреждения об отсутствии
PipeWire, системного D-Bus и устройств относятся к контейнеру; аппаратные
интеграции на ноутбуке ещё не проверены.

Полная подготовка установщика с реальным Ndot 57 прошла `niri validate`.
Пять автоматических проверок покрывают поток событий Niri, миграцию исходного
конфига, сохранение биндов, ч/б палитру, применение и откат файлов.

Скриншоты в `screenshots/` сняты с этой работающей версии. На них тестовый
город Berlin и метрики контейнера, а не данные ноутбука пользователя.
